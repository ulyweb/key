ENTERPRISE KEY & PASSWORD FORTIFICATION

SYSTEM VAULT v2.4 · How-To

Open SystemVault_v2.4.html in any modern browser. It is one offline file: no install, no server, no CDN.

1 · Fortify a weak password

  1. Press Enter on the welcome screen, then open Fortify Password (or press F).
  2. Type or paste the existing password. The length, strength meter and the Weakness Report update live and offline.
  3. Pick a similarity level (below) and a minimum trusted-entropy floor (64 / 80 / 96 / 128 / 192 / 256 / 512 bits).
  4. Press FORTIFY. Use Reveal, Copy or QR to deliver it.
  5. Change the password on the real system, then Purge memory (Shift+X).

Honest limit: anything kept from the old password adds zero trusted bits, because an attacker is assumed to know it. The vault counts only bits drawn from the CSPRNG and reports them as “trusted entropy”.

3 · How the entropy is mixed

Every random byte is crypto.getRandomValues ⊕ SHA-256(pool ∥ counter). The pool is fed by pointer movement, keystroke timing (never key values), high-resolution timing jitter and WebCrypto digests. XOR with an independent stream cannot reduce entropy below the CSPRNG, so the extra sources are defence-in-depth. All choices use rejection sampling (no modulo bias). See Entropy Sources for live counters and a smoke test (monobit + runs; not a certification).

4 · Other features

  • Key Generator — password or EFF-wordlist passphrase (7,776 words, 12.9 bits/word), batch of 10, seven integration modes (including Embed, which keeps the base whole but hides it mid-string) with an optional base modifier (counted as weak, never as random bits).
  • Character Set — choose lowercase, uppercase, digits, braces, punctuation, dashes, math, logograms, quotes or extended (Latin-1) groups, add your own characters and exclude any you do not want. Pools are de-duplicated and trusted bits are computed from the real pool size.
  • Pattern lock input — in Fortify choose Draw a pattern, or use a pattern as the generator's base modifier. Grids from 3×3 to 6×6 follow Android rules (min. 4 dots, no jumping over unused dots). A 3×3 pattern has only 389,112 possibilities (about 18.6 bits), so it is scored as weak and always fortified into a Fresh random password. Patterns stay in memory only, are hidden after drawing, and never print.
  • Airgap QR — shows a result as a locally drawn QR code to move it to a phone without a clipboard.
  • Policy Presets — Basic / Standard / High / Vault. Rotation Checklist — the steps that make a new password count.
  • Audit Ledger — SHA-256 hash chain of metadata only. Verify names the first broken block.
  • Using your own text — in the Key Generator, How should your text be mixed in? puts the text from the base field into the key (append, prepend, shuffled together, or hidden inside the random part); only the random parts count as trusted bits. The optional fold my text into the entropy pool checkbox also feeds a SHA-256 hash of it into the pool as an extra source: it adds 0 trusted bits and cannot weaken the output. Purge reseeds the pool.
  • Opening page — Settings → Opening page chooses what is open every time the page loads: Fortify a password (default), Key generator, Entropy sources, Guided tour, or Home banner only. The choice is saved in this browser; Default View applies it without reloading.
  • Walkthrough — the Guided tour button (or G) opens the tour on demand, Alt+P to auto-play. Command palette — Ctrl+K. Settings — P.

5 · Privacy & safety

  • Typed passwords and generated keys are never written to storage, the ledger, exports or toasts. They are wiped on Purge, after the idle timeout (default 2 min) and when the tab is hidden.
  • The only outbound request is the Contact Admin message you choose to send. A Content-Security-Policy in the file enforces this, and the form refuses to send text containing a password held in the tab.
  • Printing masks all secrets. Clipboard clearing is best-effort.
  • Use an uncompromised device. If the old password is still in use on a real account, rotate it.
